# P8-2 结果交互：需求与验收草案

- 状态：范围、实现和本子项验收已完成；结果纳入 P8 总回归
- 版本：v1.0
- 前置：P6 查询 API、P8-3 语义目录配置化已完成

## 1. 背景与目标

现有前端已按查询结果自动展示指标卡、折线图、柱状图和表格，但结果表不能交互排序，也没有导出。P8-2 补足轻量结果复核能力，不增加新的后端查询条件或改变指标口径。

## 2. 范围

### 本轮包括

- 对结果表的“名称”及每个结果列排序；再次点击当前排序列反转方向。
- 将当前结果表导出为 CSV；列、行、顺序和表格一致。
- CSV 使用 UTF-8 BOM，正确引用逗号、引号和换行；对可能被表格软件当作公式的文本值做保护。
- 指标卡、折线图/柱状图及其附带表格继续使用现有查询结果；导出不重新查询。

### 本轮不包括

- 页面上新增日期/类目筛选器、服务端过滤或重新查询。
- 用户自定义图表类型、列选择、Excel/PDF 文件格式。
- 对 UQ 范围、指标定义、查询 SQL 或权限行为做变更。

## 3. 功能要求

| ID | 要求 |
|---|---|
| P82-FR-01 | 可排序结果表必须允许按名称或任一展示指标列升序/降序排序；默认展示顺序保持后端结果顺序。 |
| P82-FR-02 | 当前排序字段和方向需通过表头状态向键盘/辅助技术用户可识别；点击同一表头切换方向。 |
| P82-FR-03 | CSV 必须包含可读中文表头、当前展示行、当前表格顺序及原始值；金额不得带格式化货币符号，避免破坏机器可读数值。 |
| P82-FR-04 | CSV 文本正确处理分隔符、引号、换行；公式样式的非数值文本必须转义。 |
| P82-FR-05 | 导出动作不调用问数 API，不更改页面会话、解析条件或查询结果。 |
| P82-FR-06 | 空结果维持现有空状态，不提供空文件下载。 |

## 4. 验收标准

| ID | 覆盖 | 通过条件 |
|---|---|---|
| P82-AC-01 | FR-01/02 | 名称、金额和数量列可升降序切换；相同值排序稳定；键盘可聚焦和操作表头。 |
| P82-AC-02 | FR-03 | 导出的 CSV 表头、行数、字段和排序与当前表格一致；金额是纯十进制值。 |
| P82-AC-03 | FR-04 | 含逗号/引号/换行的数据被正确引用；以 `=`, `+`, `-`, `@` 开头的非数值文本不会作为表格公式执行。 |

| P82-AC-05 | FR-06 | 空结果不显示可用导出按钮。 |

## 5. 实施顺序

1. 在结果表加入可访问的排序状态和稳定排序。
2. 加入 CSV 编码、公式保护和下载按钮。
3. 执行前端 typecheck/build、P6 HTTP Golden、完整工程回归；人工检查正常金额、负值和空结果展示。

## 6. 范围决定

项目方确认：P8-2 只做表格排序和 CSV 导出；暂不增加日期/类目交互筛选，以避免引入新的查询计划与服务器端过滤语义。若项目方后续要求筛选，本需求需扩展 API 契约和查询安全验收后再实现。
